# Googleスプレッドシート連携機能 使用ガイド

## 📊 概要
この機能により、1日の売上データを自動的にGoogleスプレッドシートに送信できます。お店や個人が簡単にスプレッドシートを変更して利用できるよう、汎用性を重視した設計になっています。

## 🔧 事前準備

### 1. Googleスプレッドシートの準備
1. Google スプレッドシートで新しいシートを作成
2. 共有設定を「URLを知っている人のみ閲覧可能」に変更
3. 1行目にヘッダーを作成（推奨）：
   ```
   日付 | 売上 | 客数 | 組数 | 取引数
   ```

### 2. Google Cloud Console でAPI設定
1. [Google Cloud Console](https://console.cloud.google.com/) にアクセス
2. 新しいプロジェクトを作成（または既存プロジェクトを選択）
3. 「APIとサービス」→「ライブラリ」から「Google Sheets API」を有効化
4. 「APIとサービス」→「認証情報」から「APIキー」を作成
5. APIキーの使用制限を設定（推奨）：
   - API制限：Google Sheets API のみ
   - アプリケーション制限：HTTP リファラー（ドメインを指定）

## 🚀 使用方法

### 1. 基本設定
1. 売上分析システムで「スプレッドシート連携」カードをクリック
2. 以下の情報を入力：
   - **スプレッドシートURL**: 作成したスプレッドシートの共有URL
   - **Google Sheets API Key**: Cloud Consoleで取得したAPIキー  
   - **書き込み先シート名**: データを書き込むシートの名前（デフォルト：「売上データ」）

### 2. 接続テスト
1. 「🔍 接続テスト」ボタンをクリック
2. 成功メッセージでスプレッドシートのタイトルが表示されることを確認

### 3. 設定保存
1. 「💾 設定保存」ボタンをクリック
2. 設定がブラウザに保存され、次回以降は自動で読み込まれます

### 4. データ送信
1. 「📤 今日のデータ送信」ボタンをクリック
2. その日の売上データが自動集計されてスプレッドシートに追加されます

## 📋 送信されるデータ形式

| 列 | 内容 | 説明 |
|---|---|---|
| 日付 | MM/DD | その日の日付 |
| 売上 | 数値 | その日の総売上金額 |
| 客数 | 数値 | その日の総客数 |
| 組数 | 数値 | その日のユニーク顧客数 |
| 取引数 | 数値 | その日の取引回数 |

## 🔒 セキュリティと注意点

### ⚠️ **重要なセキュリティ警告**
**現在の実装はテスト環境専用です。本番環境では以下の対策が必須です：**

#### 本番環境での推奨セキュリティ対策
1. **サーバーサイドプロキシの実装**
   - バックエンドサーバーでAPIキーを管理
   - フロントエンドから直接Google APIを呼ばない
   
2. **環境変数での管理**
   ```bash
   # .env ファイル（Git除外）
   GOOGLE_SHEETS_API_KEY=your_api_key_here
   SPREADSHEET_ID=your_sheet_id_here
   ```

3. **OAuth認証の実装**
   - ユーザー個別の認証フローを採用
   - APIキーではなくOAuth 2.0 トークンを使用

#### 現在の実装での最低限の対策
- APIキーは**Base64エンコード**で難読化（完全な暗号化ではありません）
- ブラウザ保存時にセキュリティ警告を表示
- API制限設定の強制確認

### テスト環境でのセキュリティ対策
- **APIキー制限設定**は必須：
  - HTTP リファラー制限
  - 特定APIのみ許可（Google Sheets API）
  - 使用量制限の設定
- **スプレッドシート権限**は「URLを知っている人のみ」に限定
- **APIキーの定期更新**（少なくとも月1回）
- **テスト専用APIキー**を使用（本番APIキーは別管理）

### 注意点
- データは追記形式で書き込まれます（既存データは保持）
- 同じ日付のデータを複数回送信すると重複します
- インターネット接続が必要です
- Google Sheets APIの利用制限にご注意ください
- **APIキーがブラウザに保存される**ことのリスクを理解してください

## 🛠️ トラブルシューティング

### よくあるエラーと対処法

#### 「❌ 接続失敗: HTTP 403」
- APIキーが無効または制限設定に問題
- Google Cloud ConsoleでAPIキーの設定を確認

#### 「❌ 無効なスプレッドシートURL」
- URLの形式が正しくない
- 正しい共有URLをコピーして使用

#### 「⚠️ 今日の売上データがありません」
- その日の売上データが売上CSVに含まれていない
- データの日付形式を確認

#### 「❌ データ送信失敗: HTTP 404」
- スプレッドシートIDが正しくない
- シート名が存在しない

## 🔄 店舗別の設定変更

### 新しいスプレッドシートに変更する場合
1. 新しいGoogleスプレッドシートを作成・設定
2. 設定画面で新しいURLを入力
3. 必要に応じてシート名も変更
4. 「接続テスト」で動作確認
5. 「設定保存」で新しい設定を保存

### APIキーの更新
1. Google Cloud Consoleで新しいAPIキーを作成
2. 古いAPIキーを無効化
3. 設定画面で新しいAPIキーを入力
4. 「接続テスト」で動作確認

## 📈 活用例

### 日次レポートの自動化
- 毎日の営業終了時に「今日のデータ送信」をクリック
- スプレッドシートで自動的にグラフや分析を作成
- 複数店舗のデータを1つのスプレッドシートに集約

### 週次・月次分析
- スプレッドシートの機能を使用して週次・月次の集計を自動化
- ピボットテーブルやグラフで視覚的な分析
- Google Data Studioとの連携でダッシュボード作成

- スプレッドシートの共有設定とAPIキーの制限設定を再確認
- Google Cloud Consoleでの課金設定とAPI使用量を確認
