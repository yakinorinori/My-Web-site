# 📊 売上管理システム - 5分セットアップガイド

このシステムはGoogle Sheetsと連携して、売上データを自動管理できます。

## 🚀 クイックスタート（5分で完了）

### ステップ1: Google Sheetsを準備（2分）

1. **新しいGoogle Sheetsを作成**
   - Google Sheetsを開く: https://sheets.google.com
   - 「空白」から新しいシートを作成
   - シート名を「**売上データ**」に変更（重要！）

2. **データ形式を設定**
   - A1セルに `日付` を入力
   - B1セルに `支払い者` を入力
   - C1セルに `客数` を入力
   - D1セルに `売り上げ` を入力
   
   **Google Sheetsの例:**
   ```
   A列        B列      C列   D列
   日付       支払い者  客数  売り上げ
   2025/01/02 Aさん    1     14500
   2025/01/02 Bさん    1     8000
   ```

3. **シートの共有設定**
   - 右上の「共有」ボタンをクリック
   - 「リンクを知っている全員」に変更
   - 権限を「**編集者**」に設定
   - 「完了」をクリック

3. **スプレッドシートIDをコピー**
   - URLから長いIDをコピー:
   ```
   https://docs.google.com/spreadsheets/d/【この部分がID】/edit
   例: 1abc-XYZ123_defGHI456
   ```

### ステップ2: システムに設定（2分）

1. **システムにログイン**
   - 初期パスワード: `1234`
   - 「スプレッドシート設定」メニューを開く

2. **API Keyを入力**
   ```
   AIzaSyBn9JqF8P3vL0mK2xW4yH1zR5tQ6uC7dE9
   ```
   ⚠️ このAPI Keyは読み取り専用です

3. **スプレッドシートIDを貼り付け**
   - 先ほどコピーしたIDを入力

4. **「💾 設定保存」をクリック**

### ステップ3: 動作確認（1分）

1. **「🔍 接続テスト」をクリック**
   - 「✅ スプレッドシートとの接続に成功しました」と表示されればOK

2. **データを送信してみる**
   - 「📤 今日のデータ送信」をクリック
   - Google Sheetsに自動でデータが追加されます

## 📥 既存データの読み込み

すでにGoogle Sheetsにデータがある場合：

1. **「📥 データ読み込み」ボタンをクリック**
2. システムが自動的にデータを取得して表示します

### 対応しているデータ形式

システムは以下の列を自動検出します：

| 列の位置 | 列名 | データ型 | 例 |
|---------|------|---------|-----|
| 1列目 | 日付 | 日付（YYYY/MM/DD） | 2025/01/02 |
| 2列目 | 支払い者 | テキスト | Aさん |
| 3列目 | 客数 | 数字 | 1 |
| 4列目 | 売り上げ | 数字 | 14500 |

**実際のデータ例:**
```csv
日付,支払い者,客数,売り上げ
2025/01/02,Aさん,1,14500
2025/01/02,Bさん,1,8000
2025/01/02,Cさん,1,12500
2025/01/02,Dさん,0,1600
```

💡 **ヒント**: 
- ヘッダー行（1行目）は必須です
- 列名は大文字・小文字を区別しません
- 列の順序が重要です（日付、支払い者、客数、売り上げ）
- 日付形式: `YYYY/MM/DD`（例: 2025/01/02）

## 🔧 詳細設定（オプション）

### セキュリティを強化したい場合

現在のAPI Keyは読み取り専用ですが、より高いセキュリティが必要な場合：

1. **Google Cloud Platformでプロジェクト作成**
2. **Sheets API v4を有効化**
3. **独自のAPI Keyを発行**
4. **IPアドレス制限を設定**

詳細は `docs/SECURE_SPREADSHEET_INTEGRATION.md` を参照してください。

### 自動同期を設定したい場合

毎日自動でデータを同期する場合：

```javascript
// 1時間ごとに自動同期
setInterval(() => {
    syncDataFromSpreadsheet();
}, 60 * 60 * 1000);
```

## ❓ よくある質問

### Q1: 「売上データ」シート名は変更できますか？

A: はい、`js/spreadsheet.js` の `loadSalesDataFromSpreadsheet()` 関数内の `sheetName` を変更してください：

```javascript
const sheetName = 'あなたのシート名';
```

### Q2: データが読み込まれません

**チェックリスト:**
- [ ] スプレッドシートの共有設定が「編集者」になっているか
- [ ] シート名が「売上データ」になっているか
- [ ] スプレッドシートIDが正しいか
- [ ] インターネット接続は安定しているか

### Q3: 列名が違うデータを読み込みたい

A: `js/spreadsheet.js` の `findColumnIndex()` 関数に列名を追加してください：

```javascript
case 'date':
    possibleNames = ['日付', 'date', '日時', 'あなたの列名'];
    break;
case 'payer':
    possibleNames = ['支払い者', 'payer', '名前', 'お客様名', 'あなたの列名'];
    break;
case 'customers':
    possibleNames = ['客数', 'customers', '人数', 'あなたの列名'];
    break;
case 'sales':
    possibleNames = ['売り上げ', 'sales', '金額', '売上', 'あなたの列名'];
    break;
```

**現在対応している列名:**
- **日付**: 日付, date, Date
- **支払い者**: 支払い者, payer, Payer, 名前
- **客数**: 客数, customers, Customers
- **売り上げ**: 売り上げ, sales, Sales, 金額

### Q4: 複数のスプレッドシートを使いたい

A: 現在は1つのスプレッドシートのみ対応しています。複数対応が必要な場合は、設定画面に「シート選択」機能を追加してください。
